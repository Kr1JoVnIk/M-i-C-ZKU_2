# Factorization and Primality Testing Algorithms

Implementation and comparative analysis of number-theoretic algorithms and their applications in cryptography. Implemented in C++ (C++17 standard).

## Project Structure
*   `task1_LAB2.cpp` — Implementation of integer factorization algorithms. 
*   Trial division method. 
*   Fermat's factorization method.
*   `task2_LAB2.cpp` — Implementation of primality and perfect number tests. 
*   Sieve of Eratosthenes (finding all primes up to N). 
*   Perfect number check.

## Build and Run
```bash
g++ task1_LAB2.cpp -o task1 -O2
g++ task2_LAB2.cpp -o task2 -O2
./task1
./task2
```
